# Slitherify
Some enhancements for slither.io game.

## Features

- Zoom: Adjust your view for better control
- Unlock all cosmetics: Access all hats (others will see your hat, and you'll see theirs)
- Overlay: Displays real-time FPS and ping
- Nickname memory: Saves your last-used nickname locally (no re-entry after reloading)

## Install

> [!WARNING]
> Tampermonkey 5.2.0+ users: Enable Developer Mode or switch to Tampermonkey MV2.

1. First install [Tampermonkey](https://www.tampermonkey.net) (Safari alternative: [UserScripts](https://apps.apple.com/app/userscripts/id1463298887))
2. [Install the script](https://raw.githubusercontent.com/dermv/slitherify/main/slitherify.user.js)
3. Open [slither.io](https://slither.io) and enjoy
